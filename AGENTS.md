# AGENTS.md — правила работы в этом репозитории

## Что здесь происходит

Проект — HD-модификация интерфейса игры Lethal Dreams (рус. «Смертельные Грёзы»,
студия Boolat Games, издатель Russobit-M, 2003). Агент развивает инструменты
и патчи и держит состояние установки игры проверенным. Перед изменениями читают:
`README.md`, `docs/INDEX.md`, `docs/STATE.md`, `docs/VERIFY.md`, `docs/PATCHES.md`,
`docs/PIPELINE.md`; наблюдения по темам — `docs/OBSERVATIONS_ENGINE.md`,
`docs/OBSERVATIONS_UI.md`, `docs/OBSERVATIONS_FONT.md`, `docs/OBSERVATIONS_TEXTURE.md`,
грабли — `docs/PITFALLS.md`, опровергнутые утверждения — `docs/CONTRADICTIONS.md`,
хроника сессий — `docs/archive/SESSION_LOG.md`.

## Железные правила

1. **Игра только для чтения.** Установленная игра — единственный экземпляр;
   запись в неё — только явным `--install` проверенных скриптов
   (`tools/pyc/install_patch.py`, `tools/exe/*` с `--install`,
   `tools/fonts/gen_font4x.py --install`, `tools/fonts/restore_fonts.py --install`).
   Эксперименты — на копиях/scratch-деревьях.
2. **Канонические команды** — `python3 tools/<dir>/<script>.py` из корня репозитория
   (список: `docs/PIPELINE.md`). Скрипты `tools/archive/` исторические: их не правят
   и не запускают напрямую.
3. **Тесты writes** — только на scratch-деревьях (`LD_CONFIG` с другим `game.root`).
   Мок-дерево игры создаётся полной копией установки и портитцется; после тестов
   установка сверяется снапшотом (diff обязан быть нулевым).
4. **Личные пути**: в ядре (`paths.py`, publishable-инструменты, docs, README) не
   появляются. Личные пути — в `config.toml` (не в git) и исторически в
   `tools/archive/`. `config.example.toml` — только плейсхолдеры.
5. **`PYTHONDONTWRITEBYTECODE=1`** при всех запусках.
6. Скрипты, компилирующие игровые модули, используют интерпретатор **2.2.3**
   (magic pyc `ed2d0d0a`). Пайплайн и рецепт .pyc: `docs/PIPELINE.md`, `docs/PATCHES.md`.
7. Файлы декомпиляции (`decompiled_fixed/**`) — производные от игрового bytecode,
   локальные; их не коммитят.
8. Изменения фиксируются коммитами (схема — раздел «Коммит» ниже); состояние — `docs/STATE.md`.

## Проверка

- `python3 tools/check_state.py --quick` — строгий CI-ярус; обязан быть rc 0 после
  всех записей.
- `python3 tools/check_state.py --full` — полный отчёт (мягкие известные расхождения
  помечаются KNOWN).
- `python3 tools/check_state.py --untouched` — неприкосновенные ассеты.
- Перед и после команд, пишущих в игру: снапшот дерева (md5+mtime), diff обязан
  совпасть с ожидаемым.

## Known drifts (не «починить», а «знать»)

- `ui/cursor.pyc` в установке — свой патч версии 6 (drift, разбор md5,
  `docs/VERIFY.md`).
- `ui/olmenu.pyc` в установке — приватная историческая сборка (`DRIFT_KNOWN`,
  `docs/PATCHES.md`).
- `data/video/boolat.wmv`, `data/video/russobit_r.wmv` — отсутствуют в современных
  установках (allowlist).

## Краткость записей (бюджет)

- **Docs фиксируют только принятые решения.** Запись = (1) что принято, (2) где
  реализовано — файл + константа/функция, (3) эталон установленной сборки (md5).
  Бюджет: **≤3 строки на решение**; 4-я строка — только ссылка на `docs/PITFALLS.md`,
  если есть грабля.
- **Процесс в docs не пишется.** Замеры, прогоны съёмки, A/B, rc ярусов чекера,
  снапшот-diff, «сначала сделали X, потом Y», число щелчков/пикселей/байтов —
  не фиксируются: это вывод инструментов, он воспроизводится командой из
  `docs/PIPELINE.md`. Разбор механизмов движка (как работает код) — в
  `docs/OBSERVATIONS_*`, без narration о том, как дошли до понимания.
- **Грабли** — symptom → причина → обход, один блок на граблю, `docs/PITFALLS.md`.
  Опровергнутые утверждения — `docs/CONTRADICTIONS.md`.
- **`docs/STATE.md` — состояние, а не хроника**: секция = текущая истина
  (константы, md5-эталоны, дрейфы). Секции «Сессия …» не пишутся; решение правит
  секцию состояния, прежний текст сворачивается в новую истину.
- **`docs/archive/SESSION_LOG.md`** — хроника дат: одна дата = ≤3 строки.
- **Сжатие по бюджету применяется и к существующему тексту**: при правке секции
  её содержание приводится к бюджету, ничего сверх бюджета не добавляется.

## Коммит

- Сообщение: что принято + где реализовано, **≤2 строки** (subject + одна строка).
- Запрещено: md5-цепочки, rc-отчёты ярусов, снапшот-diff, текст из docs, описание хода работы.
- Один коммит = одно принятое решение (или одна связная правка docs).


## Правила работы (от пользователя)

Перенесены дословно из рабочих заметок сессий (формат маркеров `[U]` сохранён). Пояснения:
«этот файл» — правила записывались в единые рабочие заметки; они распределены по тематическим
`docs/**` (указатель — `docs/INDEX.md`). `decompiled_snap/` — историческая база, удалена;
текущая база правок — `decompiled_fixed/` (`docs/PIPELINE.md`).

- `[U]` Переделка 16:9 — **мелкими итерациями**, проверка пользователем на контрольных точках.
- `[U]` **4:3 — отображение сохраняется текущее** (regression-критерий каждой итерации).
- `[U]` Целевая геометрия 16:9 (3840x2160): UI целиком в 4:3-области по центру, чёрные
  полосы по бокам, мировая сцена на весь экран.
- `[U]` Рабочие режимы к концу: 1920x1440, 1440x1080, 2880x2160 (все k=1) + 3840x2160.
- `[U]` **`.pyc` в игре меняем только дорабатываемые скрипты, остальные — родные.**
- `[U]` Изменённые скрипты — в отдельном каталоге `patches/`; общую декомпилированную
  tree (`build/`, `decompiled_snap/`) не трогать.
- `[U]` Снимать **только окно** (без полного рабочего стола); съёмка DPI-aware (см. ниже).
- `[U]` **Задания сабагентам — на английском** (промпт целиком); отчёты сабагентов, docs и
  коммиты — по обычным правилам проекта.
- `[U]` **Что пользователь принял — записывать как решение (по бюджету выше).**
  Дословные реплики, ход обсуждения и промежуточные проверки не записываются.
- `[U]` Главное меню игры **без кнопок**: при наведении в определённые точки загораются
  глифы, появляется текст пункта меню.
- `[U]` **Закрывать игру, когда она больше не нужна** (`taskkill /F /IM LETHALDREAMS.EXE`):
  окно 3840x2161 перекрывает экран и мешает пользователю. Между итерациями (сборка, анализ,
  правка скриптов, замеры снимков) игра должна быть остановлена; запускать только на прогон
  съёмки и гасить сразу после.
- `[U]` **Интерпретатор 2.2.3 — в untracked каталоге внутри проекта** (`vendor/py223/`,
  `.gitignore`; `config[py223.dir]`), не в temp. Собирается из официальных архивов
  python.org; имена `Lib/` — точный регистр источника, файлы создаются нативными
  инструментами Windows. Состав и замеры — `docs/TOOLS.md`, «Тулчейн», пункт
  «Дерево интерпретатора»; грабля регистра имён модулей — `docs/PITFALLS.md`,
  раздел «Импорт 2.2.3 чувствителен к регистру имени модуля (плоский дамп установщика
  не импортируется)».
