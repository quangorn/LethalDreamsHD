# docs/archive — выполненные планы, исследования, handoff и старые заметки

Сюда перенесены документы, которые выполнили свою роль: постановки задач, планы,
исследования, передачи результатов (handoff) и архив старых заметок. Факты, числа,
md5, offsets, VA, размеры, термины и формулировки **не правятся**: содержание
зафиксировано как есть, включая устаревшие термины и опечатки. Два разрешённых
исключения (зафиксированы здесь):
1. Личные пути заменены нейтральными формами (`config[game.root]`, `py223.dir`,
   `<scratch>/…`, «приватный рабочий каталог») — публикация не содержит личных путей;
   это замена пути, не содержания факта. Затронуты `NOTES_OLD.md` (8 замен),
   `RESEARCH_PY_DECOMPILE.md` (15 замен), `TASK_phase5_handoff.md` (6),
   `TASK_battle_trace_h2.md` (6), `PLAN_BATTLE_AI_PORT.md` (3),
   `HANDOFF_ldhook.md` (1), `ISSUE_tex_upscale.md` (1).
2. Ссылки на файлы дополнены адресом и статусом: путь репозитория (источник в git),
   `config[game.root]/…` (файл установки), артефакт прогона
   (`scratch_dir('ld')/…`, `paths.cache_dir('cave')/…`, `paths.btf_backup_dir()/…` —
   пересоздаётся скриптами, в git не входит), «приватный архив сессий …, entry …»,
   «утрачен: покрытия нет ни в git, ни в приватных архивах сессий».
   Текст ссылки дословный, добавляется только адрес/статус.
Актуальные проверенные знания — в `docs/STATE.md`, `docs/VERIFY.md`,
`docs/PATCHES.md`, `docs/PIPELINE.md`, `docs/TOOLS.md`, `docs/KNOWLEDGE.md`,
`docs/CONTRADICTIONS.md`; рабочие заметки прошлых сессий распределены по тематическим
документам `docs/**` (бывший `docs/NOTES.md` удалён; указатель — `docs/INDEX.md`).

## Правила

- Файлы здесь — **не канонические**: по ним сверяют историю решений и источники
  измерений, они не описывают текущее состояние установки.
- Командные формы и пути в этих документах исторические: канонические команды —
  `docs/PIPELINE.md`, текущее состояние — `docs/STATE.md`.
- Ссылки из активных документов на эти файлы записаны как
  `docs/archive/<имя>.md`; ссылки из архивных документов друг на друга остались
  bare-именами (файлы лежат в одном каталоге).
- `tools/archive/README.md` — указатель на архивные **скрипты**, этот файл —
  указатель на архивные **документы**.
