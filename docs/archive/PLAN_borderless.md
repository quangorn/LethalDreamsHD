## Целевые режимы (ровно два, без exclusive fullscreen)
1. **Оконный** = `hd.cfg F=0` — окно с рамкой, размер любой (цели: 1920x1440,
   1440x1080, 2880x2160). Рендер per-axis, мышь: X = `P/sx`, Y = `P/sy`.
2. **Borderless fullscreen** = `hd.cfg F=1` — движковая fullscreen-ветка (popup +
   topmost на весь desktop), modeset **не трогается**. Мышь: X = `P/sx`, Y = `P/s`
   (uniform). Центрирование подтверждено расчётом и hd7-подтверждением пользователя.

Флаг `F` = режим движка (внутренняя математика мыши/рендера), единственный источник
семантики; никаких констант вида `HD_BORDERLESS`. `hd.cfg` остаётся одной строкой
`W H BPP F`.

## Формулы hd_scale (итог)
- `k = h*1024 / (w*768)`, `dx = (1024 - 1024k)/2` — из hd.cfg (НЕ из GetScreenSize).
- Позиция X движку: `EC(c) = k*c + dx`; позиция Y: `EY(c) = c`.
- Размер X: `SC(w) = k*w` (без dx); размер Y: `EY(h) = h`.
- Фон (billboard w>=1000, h>=700): pass-through без масштаба (мир на весь экран).
- Мышь X: `MC(m) = (m - dx)/k`; мышь Y:
  - F=0 (окно): `MY(m) = m` (движок отдаёт per-axis `P/sy`; замер hd11/hd15);
  - F=1 (borderless): `MY(m) = m/k` (движок отдаёт uniform `P/s`; hd7, расчёт центра).
- Текст: font size × k; leading/rows/TextDY без масштаба; TextDX × k.
- Метрики: `GetTextWidth/GetFontSize` ÷ k; `GetTextHeight` identity.
- Identity-гарант 4:3: при k==1 все обёртки вызывают оригинал оригинальными аргументами.

## Патч бинарника (LETHALDREAMS.EXE) — уточнён 2026-11-14 после REA-разбора
Реального modeset движок **не делает**: `SetDisplayMode` при `F=1` =
`ChangeDisplaySettingsA(&devmode, CDS_TEST)` (проверка поддержки) +
`SetWindowPos(hwnd, HWND_TOPMOST, 0,0,w,h,0)`. Патч «ChangeDisplaySettings → nop»
**не нужен**. Оконный (`F=0`) режим тоже делает popup topmost на размер окна.
1. Мигание при смене фокуса лечится патчем SW_HIDE (уже применён и подтверждён
   пользователем): rva 0x49a571 (fileoff 632177) `6A 00` → `6A 01`.
2. Опционально (рамка в windowed): `push 0x86000000` (rva 0x4249a9, fileoff 149929)
   → `push 0x80000000` — снять WS_THICKFRAME/WS_VSCROLL, popup без рамки. Не применялся.
3. `WS_EX_COMPOSITED` невозможен (классы CS_OWNDC; CreateWindowExA возвращает
   NULL/err 87 — проверено P/Invoke-тестом).
4. Бэкап оригинала: `backup_orig/LETHALDREAMS.EXE.orig`, md5
   `7943036fbd1233a0dbd43228f129cfc7`.

## Изменения в patches/
- `hd_scale.py`: убрать `HD_BORDERLESS`; `MY(m)`: F==0 → `m`, F==1 → `m/k` (по глобальному
  `HD_F` из `HD_Init(w,h,f)`). Всё остальное текущее.
- `gamescript.pyc`: хук `HD_Init(w, h, f)` без изменений.
- `borderless.ps1`: остаётся в тулчейне (внешний fallback/проверка), НЕ входит в состав
  режима; игра запускается .exe сразу в целевом режиме.
- dxwrapper: удаляем из игры (`config[game.root]/dxwrapper.dll` (в установке отсутствует), `config[game.root]/dxwrapper.ini` (в установке отсутствует); stub уже выключен:
  `dsound_stub.bak` — EXE подхватывает системный dsound, звук проверен пользователем).

## Контрольные точки после реализации
1. Borderless `3840 2160 32 1`: фон без полос, UI-бокс x∈480..3360, точка строго под
   пальцем (центр-тест), «Изменить» открывается, radio квадратные, мигания при alt-tab нет.
2. Оконные `1920x1440`, `1440x1080`, `2880x2160` (`F=0`): контент = эталон 4:3 (identity).
3. Окно `3840x2160 F=0`: семантика per-axis, точка под пальцем.
4. Финальная 4:3-регрессия: k=1, пост-фиксов в логе ноль.
5. Звук (системный dsound), выход из игры без рестора modeset.

## Открытые вопросы
- Аномалия hd14 (borderless popup дал Y = P/s при конфиге F=0) — после патча F=1 семантика
  uniform легальна; прогон с центром-тестом закрывает.
- Остаточная лёгкая вертикальная вытянутость некоторых элементов (F=1) — «разберёмся
  потом» по словам пользователя.
