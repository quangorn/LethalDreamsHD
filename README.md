# Lethal Dreams HD patch

Неофициальная модификация интерфейса игры **Lethal Dreams** (рус. «Смертельные Грёзы»,
студия Boolat Games, издатель Russobit-M, 2003) для мониторов Full HD (1920×1080):

- системное масштабирование Windows (HighDPI) не ломает интерфейс;
- интерфейс игры масштабируется вместе с системным;
- при необходимости интерфейс масштабируется независимо от системного;
- все шрифты, курсоры и иконки пересчитаны и перерисованы в HD-разрешении;
- патчи, скрипты, измерения и документация — открытые.

## Правовая модель проекта

- Игра проприетарная. **Бинарные файлы игры в репозиторий не входят**: exe, dll, btf, cur,
  fdf, wmv, игровые .pyc — ничего из игровых поставок.
- В репозитории хранится только **авторское**: исходники скриптов патчей, исходники
  инструментов (Python), cave-байткод-исходники (.s), текстурные эскизы, патч-файлы
  (`release/patches/*.patch` — минимальные diff, применяемые к файлу игры пользователем),
  манифест с md5 и константами, документы.
- Пользователь обязан купить игру; его копию он использует как источник для применения
  патчей (все скрипты читают игру без записи; запись в игру — только через явный `--install`).
- Архивные копии, на которых построены инструменты (pristine 5.0, HD Pack 1.4.3,
  пользовательский бэкап 6.7z) **не публикуются**: они приватны.
- Патчи, скрипты, документы распространяются под MIT (см. `LICENSE`).

## Быстрый старт

1. У вас установлена игра Lethal Dreams (любой лицензионной копии достаточно).
2. Скопируйте `config.example.toml` → `config.toml`, заполните пути своей игры
   (и свои приватные пути: архивы, кэш, рабочие директории).
3. Проверить состояние:

```
python3 tools/check_state.py --full            # полный отчёт: код+ассеты+неприкосновенные
python3 tools/check_state.py --quick           # строгая быстрая проверка кода (CI)
python3 tools/check_state.py --untouched       # только неприкосновенные ассеты
```

4. Применить исправления, если checker что-то нашёл (он сам печатает нужную команду):

```
python3 tools/apply_patch.py <модуль> && python3 tools/pyc/install_patch.py <модуль>
```

`tools/apply_patch.py` лежит рядом с `tools/check_state.py` (на это указывает
`fix_command` в манифесте) — патч-файлы он ищет в `release/patches/`.

## Проверка состояния

`tools/check_state.py` — единая точка проверки, **только чтение, ничего не исправляет**.
Три яруса (см. `docs/VERIFY.md`):

- **code** (`--quick`, `--full`): exe/dll, hd.cfg, реестр, игровые .pyc по манифесту
  (`release/manifest.json`). Строгие проверки (md5) против **базовой** (= пропатченной)
  версии; для .pyc с известным drift (курсор) — разбор md5 (header/body).
- **assets** (входит в `--full`): .btf — CRC32 по правилу манифеста
  (`assets_tier`: hd_pack-записи побитово по путям, наборы шрифтов равны,
  замыкание CRC по объединению архивов),
  каталоги сканов по манифесту. Избыток/недостаток, совпадение/расхождение — печатается
  со ссылкой на скрипт восстановления.
- **untouched** (`--untouched`): всё, что патч не трогает, проверяется против трёх
  архивов (pristine / HD Pack / бэкап) по basename+size+crc. Отсутствующие в установке
  файлы игры разрешены (список glob-ов в allowlist).

Все проверки читают: конфиг `config.toml` (`LD_CONFIG`), манифест, allowlist, списки
скриптов, архивы. Личные пути в коде репозитория отсутствуют — они только в вашем
`config.toml` (и исторически в tools/archive).

## Применение исправлений

- `python3 tools/apply_patch.py <module>` — накладывает diff-патч на декомпилят
  `decompiled_fixed/<module>.py` и пишет результат в `patches/<module>.py` (LF) плюс
  компилят 2.2.3 `patches/<module>.pyc` (gitignored-артефакт, в git не входит).
  Контексты сверяются построчно; при несовпадении применения или расхождении md5
  результата с манифестом (`py_md5`) ничего не пишется и печатаются ожидаемая/
  фактическая строки. Повторный прогон идемпотентен. Модули:
  `gamescript, ui/ui, ui/cursor, ui/olmenu, ui/battlemenu, ui/btutorial`. Запись в игру —
  только с `--install` (делегирование install_patch.py).
- База декомпилята создаётся из **вашей** копии игры:
  `python3 tools/pyc/decompile_lit.py <module>` (список инструментов и py2-only скриптов —
  `tools/pyc/README.md`).
- `python3 tools/pyc/install_patch.py <module>` — компилирует `.py` воркером 2.2.3
 (`--install` — записывает `.pyc` в игру; без флага игра не трогается, печатается
  цель записи).
- exe/dll: патчи бинаров — `tools/exe/` (`apply_baseline.py --output <файл>|--install`,
  `exepatch3.py`, `exepatch12.py --install`, `restore`); cave-патч (шрифты) собирается
  `sh tools/exe/build_cave.sh <name>` (блобы в `paths.cache_dir('cave')`).
- Установка шрифтовых листов: `python3 tools/fonts/gen_font4x.py --install`;
  курсоры и иконки упаковываются `tools/btf/pack_btf.py` (по манифесту).

## Структура репозитория

```
paths.py                общая конфигурация путей (config.toml)
config.example.toml     шаблон конфига (без личных путей)
release/                манифест, allowlist, diff-патчи *.patch
tools/check_state.py    проверка состояния (3 яруса, read-only)
tools/apply_patch.py    применение diff-патчей .pyc-модулей
tools/pyc/              декомпиляция, компиляция, установка патчей .pyc
tools/btf/              unpack/pack btf: курсоры и иконки
tools/fonts/            unpack/pack шрифтов, пиксельные измерения и пересчёт
tools/measure/          измерение скриншотов
tools/exe/              патчи exe, cave-патч, базовая цепочка exe
tools/ldhook/           .pyd-хуки в памяти (Python 2.2.3): сборка, логгер, аудит сайтов, scratch-дерево, probe
tools/archive/        [ИСТОРИЧЕСКИЙ АРХИВ] рабочие скрипты сессий (см. README внутри)
docs/                   документация: INDEX (указатель), STATE, VERIFY, PATCHES, PIPELINE,
                        TOOLS, KNOWLEDGE, OBSERVATIONS_ENGINE/UI/FONT/TEXTURE,
                        PITFALLS, CONTRADICTIONS
docs/archive/           выполненные планы, исследования, handoff, хроника сессий и
                        отменённые планы (указатель внутри)
patches/                исходники скриптов-патчей (.py; .pyc — артефакты)
```

`decompiled_fixed/`, `cfg/`, `backup/`, `resources/`, `.tmp/`, `build/`, `caches/`,
кэши сканов — рабочие директории, в git не входят (см. `.gitignore`).
`vendor/py223/` — локальный интерпретатор Python 2.2.3 для компиляций (`config[py223.dir]`);
скачивается из архивов python.org, состав и замеры — `docs/TOOLS.md`, «Тулчейн», в git не входит.

## Скрипты сессий (tools/archive/)

`tools/archive/` — исторический архив: сотни рабочих скриптов, зафиксированы как есть
(личные пути внутри них — исторические, правила де-персонализации к ним не применяются).
Они **не каноничны**, в git они нужны как доказательство истории и источник фактов;
запускать их напрямую не нужно (канонические формы — `tools/pyc`, `tools/btf`,
`tools/fonts`, `tools/measure`, `tools/exe`).

## Ключевые факты

- Базовая (пропатченная) версия: exe md5 `171319bbc170cf6e57c8d36a8ae5f50d`
  (`release/manifest.json`), cave-патч 236 байт, 12 патчных pyc.
  Цепочка exe: pristine `7943036fbd…` → exepatch3 → +2 байта → baseline
  `45e93d46…` → exepatch12 (cave) → base. Детали: `docs/STATE.md`.
- Установленная игра проверяется по манифесту; дрейфов кодового яруса нет (`ui/cursor.pyc`
  приведён к base-печати 19.11.2026, `ui/olmenu.pyc` — каноническая сборка, `MATCH`),
  checker разбирает md5 и печатает команду применения (`docs/VERIFY.md`).
- 5096 файлов установки; неприкосновенные: 2966 pristine, 1379 HD Pack (включая 30 `.map`
  с 3x-почвой), ALLOWED 728 (пользовательский бэкап/исключения), CODE 18, EXCLUDED 4,
  ARCHIVE_BASENAME 1 (`lethaldreams.dll`) — замеры: `docs/VERIFY.md`.
  `lethaldreams.dll` и `LD-setup.bat` удалены из установки по решению пользователя
  (2026-11-18) — см. `docs/KNOWLEDGE.md`.

## Документация

Начинать с `docs/INDEX.md` (указатель и порядок чтения):
`docs/STATE.md` — состояние и константы; `docs/VERIFY.md` — модель проверки, ярусы чекера и
контрольные точки; `docs/PATCHES.md` — модель патчей, рецепт .pyc и все патчи (EXE-цепочка,
borderless, шрифты, правки UI); `docs/PIPELINE.md` — пайплайны скриптов и канонические
команды; `docs/TOOLS.md` — инструменты; `docs/KNOWLEDGE.md` — выученные факты о движке;
`docs/OBSERVATIONS_ENGINE.md`/`OBSERVATIONS_UI.md`/`OBSERVATIONS_FONT.md`/`OBSERVATIONS_TEXTURE.md`
— наблюдения (рендер и геометрия мира, UI и боевой HUD, шрифты, текстуры);
`docs/PITFALLS.md` — грабли (симптом → причина → обход); `docs/CONTRADICTIONS.md` — реестр
опровергнутых утверждений; `docs/archive/**` — хроника сессий, выполненные планы и отменённые
планы. Единый файл рабочих заметок `docs/NOTES.md` удалён, содержание распределено
по тематическим документам (таблица — `docs/INDEX.md`).

## Ограничения

- Скрипты Python2.2-совместимы (игровые .pyc), инструменты — Python3.
- Окно игры не двигается системным масштабированием (ограничение Windows:
  окно, двигавшееся системным масштабом, не масштабируется).
- Полноэкранное масштабирование 1920 (растягивание exe) не реализовано —
  это отдельная исследовательская задача (`docs/KNOWLEDGE.md`).
